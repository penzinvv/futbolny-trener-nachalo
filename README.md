# Дворовый футбол. Начало

**Рабочее название проекта:** «Футбольный тренер».

Официальное название игры — **«Дворовый футбол. Начало»**. Рабочее название сохраняется только для истории разработки и внутренних обозначений.

Стартовый браузерный прототип проекта. Это каркас для итеративной разработки и тестирования, а не готовая игра.

## Уже есть
- Первый запуск: имя тренера, название команды, выбор одной из шести эмблем.
- Адаптивный главный экран в стилистике дворового футбола.
- Раздельные показатели: XP, постоянный рейтинг, сезонный рейтинг, уважение.
- Навигация по основным разделам.
- Пустые страницы для ещё не согласованных/не реализованных систем (включая «Лигу»).
- Локальное сохранение профиля в `localStorage`.

## Пока не реализовано
- Серверная авторизация и облачные сохранения.
- Начальный состав из подготовленных пользователем футболистов.
- Реальная механика тренировок, отношения, цели и рейтинги.
- Симуляция официального матча и лига.
- Античит и авторитетная серверная логика.

## Запуск локально
Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта.

## Развёртывание на Netlify
Папка публикации — корень проекта. Файл `netlify.toml` содержит минимальную конфигурацию.

**Важно:** локальное сохранение в браузере не является надёжным игровым аккаунтом и может исчезнуть при очистке данных браузера.
