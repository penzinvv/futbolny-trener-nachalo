РАДИО: 20 ТРЕКОВ

1. Поместите файлы footmusic1.mp3 ... footmusic20.mp3 в папку music.
2. В этой же папке лежит playlist.json — он уже перечисляет все 20 файлов.
3. Имена должны совпадать точно. На вашем скриншоте видны footmusic1–6 и footmusic9–20; footmusic7.mp3 и footmusic8.mp3 не видны. Если их действительно нет, добавьте их или удалите соответствующие строки из playlist.json.
4. При добавлении новых треков добавьте их имена в массив tracks файла playlist.json.
5. Опубликуйте вместе изменения app.js и music/playlist.json. GitHub для формирования списка больше не нужен.

Примечание: MP3-файлы из нового набора вы загружаете самостоятельно.
