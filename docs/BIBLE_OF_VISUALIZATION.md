# Библия визуализации — «Дворовый футбол. Начало»

**Актуальная версия:** 2.8.7  
**База кода:** 2.8.6 (`feature/2.8.6-rating-snake-defender-fix`, коммит `45d55ab1d80a2c311b55323c30312e1f84e843b0`)  
**Назначение:** единый источник истины по фоновым изображениям страниц. Исторические записи не удаляются.

## Принципы, утверждённые пользователем

1. Фон относится к свободному пространству страницы, а не к игровым и информационным окнам.
2. Существующие окна с информацией и интерактивными кнопками не перестраивать ради фона. Их заливка может быть немного прозрачной, но текст, показатели и кнопки должны оставаться читаемыми.
3. Учитывать реальную композицию каждой страницы: фоновые детали не должны конкурировать с расположенными на ней таблицами, календарём, формами или карточками.
4. Не повторять без необходимости один и тот же сюжет на разных страницах. Не делать для всех страниц стадион, ворота или мяч; тема изображения должна соответствовать содержанию раздела.
5. Для каждой страницы готовить отдельную desktop- и mobile-версию. Сначала пользователь утверждает концепцию, затем изображения загружаются пользователем в GitHub.
6. До отдельной команды пользователя не менять код для подключения новых фонов. Подключение версии 2.8.7 выполнено только после команды на интеграцию.
7. Не заменять весь код старой визуальной веткой. Все изменения встраиваются в актуальную игровую основу 2.8.6.
8. После каждой принятой модификации обновлять версию и соответствующие Библии. Номер игры, номер Библии и исторические записи различать.

## Технические правила

- Выбор фона выполняется через атрибут `body[data-page-bg]` в `src/app.js`.
- CSS хранится в `src/styles.css`; изображения не встраиваются внутрь компонентов с игровыми действиями.
- При ширине окна до 700 px подключается мобильный файл; выше — desktop-файл.
- `.pitch` сохраняет оформление игрового поля, но не использует фоновые обои страницы.
- `.onboarding` остаётся затемнённой формой создания команды; фон отображается за ней.
- Текущие страницы без отдельного утверждённого фона (FAQ, поддержка, разработчик) используют фон главной. Не назначать им случайный фон без согласования.
