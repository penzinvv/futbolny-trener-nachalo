# Аккаунт и облачное сохранение

## Что добавлено
- Регистрация и вход по электронной почте и паролю.
- Привязка гостевой Supabase-сессии к email/паролю через updateUser, чтобы сохранить прежний user ID.
- Восстановление пароля через письмо Supabase.
- Резервная копия локальной карьеры перед входом в другой аккаунт.
- Восстановление облачного снимка при входе в новом браузере.
- Защита от автоматического переноса локальной гостевой карьеры в другой пустой аккаунт.

## Что проверено локально
- `node --check src/app.js` проходит без синтаксических ошибок.
- Существующие Supabase Edge Functions `career-api`, `career-save`, `career-health` найдены и остаются без изменений.
- В базе есть таблица `career_state_snapshots`, а сохранения обслуживаются через Edge Function `career-save`.

## Что необходимо проверить вручную
1. В Supabase Authentication → URL Configuration Site URL должен быть `https://streetfootballstart.ru/`.
2. В Redirect URLs добавлен `https://streetfootballstart.ru/**`.
3. Включён Email provider. Подтверждение email включено — протестируйте письмо на отдельном адресе.
4. В браузере с существующей гостевой карьерой зарегистрируйте аккаунт и подтвердите email.
5. Откройте игру в другом браузере, войдите тем же email/паролем и проверьте восстановление карьеры.
6. Проверьте восстановление пароля.

## Важно
Изменения Supabase Auth, шаблоны писем и SMTP в Dashboard этим архивом не меняются. Сначала протестируйте сборку отдельно, не заменяя текущую опубликованную игру, пока не подтверждена регистрация и восстановление карьеры.
